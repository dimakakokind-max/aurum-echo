# AURUM | Echo 🌑

**AURUM Echo** — это анонимная лента постов, где каждый может высказаться, не раскрывая свою личность. Проект выполнен в эстетике премиального бренда AURUM: темная тема, золотые акценты и эффект матового стекла.

## ✨ Особенности

*   **Полная анонимность:** Пользователи входят через Firebase Anonymous Auth, поэтому не нужно регистрироваться или вводить личные данные.
*   **Лента в реальном времени:** Новые посты появляются мгновенно благодаря Firestore.
*   **Премиальный дизайн:** Курсор с аурой, стеклянные карточки и золотые кнопки.
*   **Простота:** Никаких сложных форм. Зашел, написал, отправил.

## 🛠️ Технологии

*   HTML5 / CSS3 (Glassmorphism)
*   JavaScript (Vanilla JS)
*   Firebase (Auth + Firestore)

## 🚀 Как запустить

1.  Включите **Anonymous Auth** и **Firestore** в консоли Firebase.
2.  Замените `firebaseConfig` в коде на свои ключи.
3.  Откройте `index.html` в браузере.
