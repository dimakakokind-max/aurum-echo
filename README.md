# AURUM | Memories 💭

Добро пожаловать в **AURUM Memories** — цифровое пространство, где каждый может поделиться своими воспоминаниями, оставить заявку или просто высказаться, не раскрывая свою личность.

Это не просто лента постов. Это место, где слова имеют вес, а анонимность дает свободу быть собой. Мы объединили эстетику премиального бренда **AURUM** с простотой и удобством современной социальной платформы.

## ✨ Особенности

*   **Полная анонимность:** Вход через Firebase Anonymous Auth. Никто не узнает, кто ты, но твой голос будет услышан.
*   **Лента воспоминаний:** Делись историями, мыслями или тем, что на душе. Всё сохраняется в базе данных Firestore и отображается в реальном времени.
*   **Заявки и предложения:** Хочешь предложить идею, заказать разработку или присоединиться к команде? Просто напиши об этом в ленте.
*   **Премиальный дизайн:** Темная тема, золотые акценты, кастомный курсор с аурой и эффект матового стекла (Glassmorphism) — всё в стиле AURUM.
*   **Мгновенная загрузка:** Новые посты появляются без перезагрузки страницы.
